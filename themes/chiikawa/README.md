# ちいかわテーマの画像

ここに次の3つのファイルを置くと、ちいかわテーマのイベントで表示されます。
無いファイルは表示されないだけで、画面は崩れません。

| ファイル | 出る場所 | 画像 | 表示の大きさ |
|---|---|---|---|
| `header.png` | ヘッダーのロゴ（「調整くん」の左） | 透過PNG・256×256 | 40×40 |
| `empty.png` | 何も無いときの案内文の上 | 透過PNG・480×480 | 112×112 |
| `celebrate.png` | 座席のシャッフルが終わったとき（約2秒） | 透過PNG・800×800 | 240×240 |

- キャラクターの周りに約8%の透明な余白を入れてください
- `celebrate.png` は暗い幕の上に出るので、2〜3pxの白いフチ取りがあると見やすくなります
- このフォルダは test 環境と本番の両方から読まれます（`scripts/promote.sh` を使わずにそのまま反映されます）
