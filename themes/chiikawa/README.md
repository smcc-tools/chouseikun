# ちいかわテーマの画像

ここに次の3つのファイルを置くと、ちいかわテーマのイベントで表示されます。
無いファイルは表示されないだけで、画面は崩れません。

| ファイル | 出る場所 | 画像 | 表示の大きさ |
|---|---|---|---|
| `header.png` | ヘッダーのロゴ（「調整くん」の左） | 透過PNG・256×256（ちいかわ） | 40×40 |
| `empty.png` | 何も無いときの案内文の上 | 透過PNG・480×480（ハチワレ） | 112×112 |
| `celebrate.png` | 座席のシャッフルが終わったとき（約2秒） | 透過PNG・1200×520（うさぎ・ちいかわ・ハチワレが車に乗った絵） | 幅340px（画面が狭いときは画面幅の88%）・高さは比率なり |
| `empty-sleep.png` | 日程調整の準備中（参加者の画面） | 透過PNG・480×480（寝ている3人） | 112×112 |
| `empty-tools.png` | まだ立替が無いとき | 透過PNG・480×480（道具を持った3人） | 112×112 |
| `vote-o.png` | ◯ の代わり（投票ボタン・回答・凡例・「全て◯」） | 丸い顔・128×128（ちいかわ） | 16〜30px |
| `vote-x.png` | ✕ の代わり | 丸い顔・128×128（ハチワレ） | 16〜30px |
| `vote-t.png` | △ の代わり | 丸い顔・128×128（うさぎ） | 16〜30px |

- キャラクターの周りに約8%の透明な余白を入れてください（横長の `celebrate.png` は約4%）
- 今の画像は、オーナーが用意したスクショから背景を抜いて（顔は丸く切って）作ったものです
- `celebrate.png` は暗い幕の上に出るので、2〜3pxの白いフチ取りがあると見やすくなります
- このフォルダは test 環境と本番の両方から読まれます（`scripts/promote.sh` を使わずにそのまま反映されます）
- `vote-*.png` は3枚とも読めたときだけ顔に置き換わります（1枚でも欠けると ◯△✕ の記号のまま）
- `empty-*.png` が無い画面は `empty.png` を使わずに画像なしになります
