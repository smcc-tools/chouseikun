# 座席の確定 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 決めた座席を「確定」でき、確定中は誤シャッフルも手動変更も起きないようにする。

**Architecture:** 次会に `confirmed` フラグを1つ追加する。表示（編集UIを描かない）・操作（各入口で早期 return）・書き込み（トランザクション内で読み直して確認）の3層で守る。書き込み層が本質的な防御で、座席まわりの書き込み12箇所が集約されている `updateActiveParty` を、既存の `mutateParties`（トランザクション＋id照合）経由に変えることで実現する。

**Tech Stack:** 素の HTML/CSS/JavaScript（ES modules）、Firebase Firestore v11.8.1、テストは `node:test`＋`tests/frontend/extract.js` の特性化テスト方式。

## Global Constraints

- 開発は `日程調整アプリ/test/index.html` に対して行う。`index.html`（本番）は直接編集しない。
- 追加費用を発生させない。Firestore の読み書き回数を増やす設計にしない。
- `confirmed` 未設定を未確定として扱う。**移行処理を書かない。**
- Firestore ルール・Cloud Functions・権限まわりは一切変更しない。
- `assignment` / `locks` / `assignmentHistory` の構造は変えない。
- 参加者の画面は確定の有無で変わらない。確定バナーも参加者には出さない。
- UI 文言は「この席で確定」「確定を解除」「🔒 この座席で確定しています」を使う。
- 確定・解除に確認ダイアログを出さない。
- 各タスクの最後に `node --test tests/frontend/*.test.js` が全件 pass すること。

```js
  async function mutateParties(partyId, apply, opts = {}) {
    return await runTransaction(db, async (tx) => {
      const ref = doc(db, 'events', eventId);
      const d = (await tx.get(ref)).data() || {};
      const parties = getParties(d).map(p => ({ ...p }));
      const i = parties.findIndex(p => p.id && p.id === partyId);
      if (i < 0) return -1;
      // 確定中の次会は変更しない。ここで最新の値を読み直すので、共同ホストが
      // 直前に確定していて自分の画面がまだ知らない場合でも止まる。
      // 「確定中でも通す操作」(解除・次会の名称変更)は呼び出し側が明示する。
      // パッチの中身から推測すると、将来フィールドが増えたときに誤って通るため。
      if (isPartyConfirmed(parties[i]) && !opts.allowConfirmed) return -2;
      const next = apply(parties, i);
      if (!next) return -1;
      tx.update(ref, { seatParties: next });
      return i;
    });
  }
```

  // mutateParties 経由にすることで、書き込みの瞬間に確定を読み直して確認できる。

  async function updateActiveParty(patch, opts = {}) {
    const target = activeParty(latestEventData || {});
    if (!target || !target.id) { showToast('保存に失敗しました'); return -1; }
    const r = await mutateParties(target.id, (ps, at) => { ps[at] = { ...ps[at], ...patch }; return ps; }, opts);
    if (r === -2) showToast('確定中のため変更できません。確定を解除してください');
    else if (r < 0) showToast('保存に失敗しました');
    return r;
  }

| # | 内容 | 判定 |
|---|---|---|
