**Goal:** 座席決めで長机を縦向きにでき、卓の間に隙間を空けた配置ができるようにする。

**Architecture:** 卓に `orient`（'h'|'v'）、次会に `freeLayout`（bool）を足すだけのデータ変更。縦向きは「見た目の90度回転」に留め、席の隣接関係は変えないので席替えロジックは無変更。空きマスの枠は「配置を調整」モード中だけ出し、隙間そのものは通常表示でも保つ。

**Tech Stack:** 単一HTMLファイル（`test/index.html`）内の素のJS + CSS。テストは `node --test` と `tests/frontend/extract.js` による関数抽出方式。

```javascript
  // 卓をグリッド位置(slot)順に並べ、空きマスを null で表した配列を返す。
  // freeLayout=true（ホストが「配置を調整」で並べた次会）では、卓数が列数で
  // 割り切れても詰めない。意図して空けた隙間が消えてしまうため。
  function normalizeTableSlots(tables, cols, freeLayout) {
    const c = Math.max(1, parseInt(cols) || 1);
    const bySlot = new Map();
    const pending = [];
    (tables || []).forEach(t => {
      const s = parseInt(t && t.slot);
      if (Number.isInteger(s) && s >= 0 && !bySlot.has(s)) bySlot.set(s, t); else pending.push(t);
    });
    let free = 0;
    pending.forEach(t => { while (bySlot.has(free)) free++; bySlot.set(free, t); });
    if (!bySlot.size) return [];
    // 卓数が列数で割り切れる場合（例：2卓×2列）は空きマスを作らず詰めて表示。
    // 割り切れない場合（例：3卓×2列＝1マス余る）のみ、余りマスの位置(slotの隙間)を保持する
    const entries = [...bySlot.entries()].sort((a, b) => a[0] - b[0]);
    if (!freeLayout && entries.length % c === 0) return entries.map(e => e[1]);
    const maxSlot = entries[entries.length - 1][0];
    const total = Math.ceil((maxSlot + 1) / c) * c;
    return Array.from({ length: total }, (_, i) => bySlot.get(i) || null);
  }
```
