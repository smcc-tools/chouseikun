# メールアドレスでのアカウント登録 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Google を使わずに、メールアドレスとパスワードで調整くんのアカウントを作れるようにする。

**Architecture:** Firebase Auth のメール/パスワードプロバイダを既存の Google と並列に有効化する。権限は `events.ownerUids` の uid ベースで、Firestore ルールと Cloud Functions は「匿名を除外する」という否定形のため**一切変更しない**。ログインの入口は4箇所あるが、すべて1つのモーダルに集約する。

**Tech Stack:** 単一HTMLファイル（`test/index.html`）内の素のJS + CSS。Firebase Auth v11.8.1（CDN・モジュール）。テストは `node --test` と `tests/frontend/extract.js` の関数抽出方式。

## Global Constraints

- 実装は必ず `test/index.html` に対して行う。`index.html`（本番）は `scripts/promote.sh` でのみ更新する。
- **Firestore ルール（`firestore.rules`）と Cloud Functions（`functions/`）は変更しない。** 変更が必要になったら設計判断が誤っている。
- 抽出方式のテストの制約：テスト対象の関数が呼ぶ**すべての関数を `loadFunctions` の抽出リストに載せる**。載せ忘れると実行時に `ReferenceError` で落ちる。
- パスワードの最小文字数は **8文字**（Firebase 既定の6文字より厳しくする）。
- ログイン失敗時、`auth/invalid-credential` / `auth/wrong-password` / `auth/user-not-found` は**同一の文言**にする（アカウント列挙対策）。理由を区別して表示してはいけない。
- 登録時の**確認メールは送らない**。パスワード再設定メールのみ、利用者が「忘れた方」を押した時に送る。
- Google ログイン（`signIn()`）の既存動作は変えない。
- 実装者はパスワードを画面やログに出力しない。`console.log` にパスワードを含めない。
- コミットメッセージは日本語。末尾に `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>` を付ける。
- 実装者は push・デプロイ・`promote.sh` を実行しない。

`test/index.html` の `function validateParticipantName(name) {` の**直前**に挿入：

```javascript
  // ── メールアカウントの入力チェック ──
  // mode: 'login' | 'signup'。DOMに触れない純粋関数として切り出し、テストで固定する。
  // ログイン時は文字数を見ない：既存アカウントが8文字未満でも締め出さないため。
  const ACCOUNT_MIN_PASSWORD = 8;
  function validateAccountInput(mode, input) {
    const v = input || {};
    const email = String(v.email || '').trim();
    const password = String(v.password || '');
    const password2 = String(v.password2 || '');
    const name = String(v.displayName || '').trim();
    const fail = msg => ({ ok: false, error: msg, displayName: '' });
    // 記号を許しつつ、@の前後とドメインのドットを必須にする
    if (!/^[^\s@]+@[^\s@.]+(\.[^\s@.]+)+$/.test(email)) return fail('メールアドレスの形式が正しくありません');
    if (!password) return fail('パスワードを入力してください');
    if (mode === 'signup') {
      if (password.length < ACCOUNT_MIN_PASSWORD) return fail(`パスワードは${ACCOUNT_MIN_PASSWORD}文字以上にしてください`);
      if (password !== password2) return fail('確認用のパスワードが一致しません');
    }
    return { ok: true, error: '', displayName: name || email.split('@')[0] };
  }

  // Firebase の認証エラーを日本語にする。
  // invalid-credential / wrong-password / user-not-found は意図的に同じ文言にする
  // （分けると総当たりで登録済みアドレスを特定できるため＝アカウント列挙）。
  function authErrorToJa(code) {
    const c = String(code || '');
    if (c === 'auth/email-already-in-use') return 'このメールアドレスは既に登録されています（Googleで登録済みの場合も含みます）';
    if (c === 'auth/invalid-email') return 'メールアドレスの形式が正しくありません';
    if (c === 'auth/weak-password') return `パスワードは${ACCOUNT_MIN_PASSWORD}文字以上にしてください`;
    if (c === 'auth/invalid-credential' || c === 'auth/wrong-password' || c === 'auth/user-not-found') {
      return 'メールアドレスまたはパスワードが違います';
    }
    if (c === 'auth/too-many-requests') return '試行が多すぎます。しばらく待ってからお試しください';
    if (c === 'auth/network-request-failed') return '通信に失敗しました。接続を確認してください';
    return 'ログインに失敗しました。しばらくしてからお試しください';
  }

```

      const input = {

        displayName: ov.querySelector('#authName2')?.value,

        ov.remove();
      } catch (e) {
        busy(false);
        setErr(authErrorToJa(e && e.code));
        console.warn('認証に失敗:', e && e.code);

      ov.querySelector('#authCloseBtn')?.addEventListener('click', () => ov.remove());

          await sendPasswordResetEmail(auth, email);

      ov.querySelectorAll('#authEmail, #authPw, #authPw2, #authName2').forEach(el =>
        el.addEventListener('keydown', ev => { if (ev.key === 'Enter') { ev.preventDefault(); submit(); } }));
    };
    render();
    document.body.appendChild(ov);
    ov.addEventListener('click', e => { if (e.target === ov) ov.remove(); });
    ov.querySelector('#authEmail')?.focus();
  }
