# イベントごとのテーマ（オリーブ／ちいかわ）

作成日: 2026-10-18
対象: `日程調整アプリ/test/index.html`
見た目の出典: Claude Design の納品物 `design_handoff_chiikawa_theme`（2026-10-18）
指示書: `docs/superpowers/specs/2026-10-18-ちいかわテーマ-ClaudeDesign指示書.md`

## 背景

調整くんの配色は「Olive Lounge」1つだけで、`:root` の CSS 変数に固定されている。
イベントごとに配色を選べるようにし、2つ目のテーマとして、ちいかわのキャラクターを使ったテーマを用意する。

### 現状の把握

- 色は `:root` の約20個のトークン（`--green` `--gold` `--clay` など）で管理され、`var(--…)` が497か所で使われている
- ただし、**トークンを通らず直書きされた色が235か所（約100種類）**ある。うちオリーブ・生成り色の淡い色は、テーマを変えても残ってしまう
- ボタンの角丸は部品ごとにばらばらで、主ボタン・副ボタン・「確定」・タブ・チップは既にピル型（999px）、◯△✕は9px、ナビは13px（スマホ11px）、全て◯✕は7px
- ヘッダーのロゴは `.header-logo::before` に CSS で描いた絵
- 本番反映（`scripts/promote.sh`）は `index.html` と `sw.js` しかコピーしない
- Firestore の作成ルールは項目を制限しておらず、更新はホスト（isOwner）なら何でも書ける。参加者の書き込みは許可キーの一覧で制限されており、`theme` は含まれない

## 要件

| # | 要件 |
|---|---|
| R1 | イベントごとにテーマを選べる。選べるのはオリーブ（既定）とちいかわの2つ |
| R2 | 作成時に選べ、作成後もホスト（共同ホストを含む）が変更できる |
| R3 | そのイベントを開いた全員（ホスト・参加者）が同じテーマで見る |
| R4 | イベントの外（トップ・マイイベント一覧）は常にオリーブ |
| R5 | オリーブの見た目は1pxも変えない |
| R6 | ちいかわでは、ヘッダー・空の画面・座席のシャッフル完了時の3か所にキャラクター画像を出す |
| R7 | 画像が無い・読み込めないときは枠ごと出さず、画面は崩れない |
| R8 | ちいかわの文字はコントラスト比4.5以上（下記の組み合わせ） |
| R9 | 追加費用を発生させない。オリーブの人には余計な通信を発生させない |

### 非目標（YAGNI）

- 3つ目以降のテーマ（仕組みは足せる形にするが、今回は作らない）
- 暗い背景のテーマ（ダークモード）
- 参加者が自分だけ見た目を変える機能
- 座席の色タグ5色の変更（保存データとして使っているため）
- 画面の構成・文言・ボタンの位置の変更

## 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| キャラクター画像 | オーナーが用意した画像をリポジトリに組み込む | オーナーの判断。サイトとリポジトリが公開されていることは確認済み |
| お祝いを出す場面 | **座席のシャッフル完了時だけ**。日程の確定時は出さない | オーナーの判断（Claude Design の提案どおり） |
| ✕・削除の色 | `#C4485F`（納品物の `#D0566C` から変更） | 納品物の値は白地で4.02と、いまのオリーブ（4.46）より読みにくい。`#C4485F` は4.73 |
| ボタンの角丸 | 部品ごとにトークンを分ける | 納品物は1つの `--btn-radius`（オリーブ仮12px）だったが、オリーブの多くは既にピル型で、1つにまとめるとオリーブが変わってしまう |
| ルールの変更 | しない | 作成ルールは項目を制限せず、更新はホストのみ `theme` を書ける |

## データ

```
events/{id}: { …, theme: 'chiikawa' }   ← 追加。未設定・知らない値はオリーブ
```

移行処理は書かない。

## 見た目（トークン）

### 仕組み

```css
:root                        { /* オリーブの値（いまの値のまま） */ }
:root[data-theme="chiikawa"] { /* ちいかわの値 */ }
```

イベントを開いたとき、テーマがちいかわなら `<html data-theme="chiikawa">` を付け、イベントの外に出たら外す。

### ② 空の画面の対象

1. まだ立替がありません。「＋ 立替を追加」から記録してください。
2. この次会の座席はまだ決まっていません。ホストの確定をお待ちください。
3. 参加者・卓を設定して「席を決める」を押すと、ここに座席表が表示されます。
4. 集合時間・お店はまだ設定されていません。
5. 精算はまだ公開されていません。
6. 日程調整の準備中です。しばらくお待ちください。

### ③ お祝い

座席のシャッフルが完了したとき（既存の紙吹雪と同じタイミング）に、全面の暗幕（`--scrim`）と中央の画像を約2秒出して自動で消す。日程の確定時には出さない。

## テーマの選び方

### 作成時

5つの作成画面（日程・精算・お知らせ・割り勘・座席）に「テーマ」の選択欄を置く。既定はオリーブ。選んだ値を作成時の保存内容に含める。

### 作成後

ナビの右端に「🎨 テーマ」を置き、押すとオリーブ／ちいかわを選べる。**ホスト（共同ホストを含む）にだけ出す。** 参加者には出さない。

### ちらつき対策

テーマはイベントのデータを読み込んでから分かるため、開いた瞬間にオリーブが一瞬見える。
前回そのイベントを開いたときのテーマを端末に記録しておき、データの到着を待たずに先に当てる。記録の読み書きに失敗しても動作は変わらない（データが届いた時点で正しいテーマになる）。

## 確かめ方

| 対象 | 方法 |
|---|---|
| オリーブが変わらない（R5） | トークン化の**前に**、全画面（ホスト・参加者）の全要素の文字色・背景色・枠の色・角丸・影をヘッドレスで記録する。置き換えの後に同じ記録を取り、1件も差が無いことを確かめる |
| ちいかわの読みやすさ（R8） | `test/index.html` の CSS からちいかわのトークンを読み出し、下の組み合わせがすべて4.5以上かを自動テストで確かめる |
| テーマ名の扱い | 未設定・知らない値・大文字などがオリーブに落ちることを単体テストで確かめる |
| 画像の場所 | test と本番で正しいパスになることを単体テストで確かめる |
| 全画面の表示 | 全ナビを開いて、カードが見えて中身があることをオリーブ・ちいかわの両方で確かめる |
| 選択と権限（R2・R3） | ホストが作成時・作成後に変えられ、参加者には切り替えが出ず、ルール上も書けないことを実測する |
| 画像が無いとき（R7） | 画像ファイルが無い状態で、枠が出ず画面が崩れないことを確かめる |

### コントラストを確かめる組み合わせ（ちいかわ）

| 組み合わせ | 期待 |
|---|---|
| `--on-brand` × `--green` | 4.5以上 |
| `--text` × `--bg` | 4.5以上 |
| `--text` × `--surface` | 4.5以上 |
| `--text-muted` × `--bg` | 4.5以上 |
| `--text-muted` × `--surface` | 4.5以上 |
| `--gold-text` × `--gold-tint` | 4.5以上 |
| `--on-dark` × `--forest` | 4.5以上 |
| `--on-brand` × `--host-badge` | 4.5以上 |
| `--clay` × `--surface` | 4.5以上 |

オリーブの `--gold-text` × `--gold-tint` は4.17で基準を下回るが、R5（オリーブは変えない）を優先し、テストの対象外とする。

## リスク

| リスク | 対応 |
|---|---|
| 直書き235か所の置き換えでオリーブの見た目が変わる | 置き換えの前後で全要素の色・角丸・影を記録して突き合わせる。差が1件でも出たら直す |
| 置き換え漏れで、ちいかわに生成り色やオリーブの淡色が残る | ちいかわで全画面を描画し、オリーブ側のトークン値と同じ色が残っていないかを数える |
| 画像の著作権 | オーナーが判断済み。サイトとリポジトリが公開されていることは伝えてある |
| 日本語フォントが重い | Google Fonts は文字の範囲ごとに分けて配信するので、使う文字の分だけ読み込まれる。ちいかわのときだけ読む |
| テーマを切り替えた直後にフォントが入れ替わり、文字の幅が変わる | `display=swap` で文字は先に出る。一瞬の入れ替わりは許容する |
