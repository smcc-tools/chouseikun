## 1. お願いしたいこと

飲み会の幹事アプリ「調整くん」には、イベントごとに選べるテーマが2つあります（オリーブ／ちいかわ）。
**ちいかわテーマの見た目を、添付の「ちいかわ公式サイト」の雰囲気に寄せてください。**

いまのちいかわテーマは、配色・丸ゴシック・キャラクター画像を入れただけで、**画面の骨組み（ヘッダー・カード・見出し・ナビの形）はオリーブと同じ**です。今回はその骨組みの見せ方まで、公式サイトらしく変えたいと考えています。

**変えるのは見た目だけです。** 画面にある部品・文言・操作の流れ・部品の並び順は変えません（理由は 3 章）。

---

## 2. 調整くんについて

飲み会・歓迎会などの幹事が使う、無料のWebアプリ（スマホ中心）です。1つのイベントURLの中に次の画面があり、ホストは下のナビで切り替えます。

| ナビ | 内容 |
|---|---|
| 日程 | 候補日ごとに参加者が ◯△✕ を付ける表。ちいかわでは ◯＝ちいかわ／✕＝ハチワレ／△＝うさぎ の顔になります |
| お店 | お店探し（外部の画面を埋め込み。今回は対象外） |
| お知らせ | 開催日・集合時間・集合場所・お店の案内 |
| 座席 | 卓と席を並べ、参加者をシャッフルして座席を決める |
| 割り勘 | 立替の記録と、誰が誰にいくら払うかの精算結果 |
| 精算 | 会費の集金と支払い状況 |

- 使う人は「ホスト（幹事）」と「参加者」。参加者は同じURLで、必要な情報だけを見ます
- テーマはイベントごとに決まり、そのイベントを開いた全員が同じテーマで見ます
- 主な閲覧環境は **スマホ（幅390px前後）**。320px〜PC（1280px以上）まで崩れないこと

---

## 3. 組み込みの仕組みと、守ってほしいこと

ちいかわテーマは、**同じHTMLに、ちいかわのときだけ効くCSSを重ねる**仕組みです。

```css
/* ちいかわのイベントを開くと <html data-theme="chiikawa"> になる */
:root[data-theme="chiikawa"] .card { /* ここに書いた見た目は、ちいかわのときだけ効く */ }
```

このため、次を守ってください。

1. **CSSだけで実現できる見た目にする。** HTMLの要素を足したり、順番を入れ替えたりはできません。飾りが要るときは `::before` / `::after`、背景画像、枠線、影などで表現してください
2. **すべてのセレクタの先頭に `:root[data-theme="chiikawa"]` を付ける。** オリーブの見た目には一切影響させません
3. **部品・文言・並び順・表示／非表示は変えない。** 隠したい部品があっても `display: none` にはしないでください（機能が消えます）
4. **◯△✕ の顔、座席の色タグ5色（オリーブ／ブラス／テラコッタ／ブルーグレー／プラム）は変えない**
5. **文字が読めること（WCAG AA・コントラスト比 4.5 以上）。** 本文・補足・ボタンの文字すべて
6. **押せる部品は指で押せる大きさ（目安 高さ32px以上）を保つ**
7. **公式サイトのロゴ・画像・文章はそのまま使わない。** 手本にするのは「雰囲気」（配色の傾向・余白・見出しの飾り方・背景の柄・角の丸み・線の太さなど）です
8. **キャラクターの絵は描かない。** 新しい画像が必要な場所は、点線の枠と寸法で示してください（オーナーがスクショから用意します）

## 7. 作ってほしいもの

### 7-1. 画面モック

**スマホ幅（390px）** で、次の画面を公式サイト風のちいかわテーマで描いてください。添付の `今の画面/` が作り替え前です。

1. 日程（ホスト）… `01`
2. 日程（参加者）… `02`
3. お知らせ（参加者）… `03`
4. 座席（ホスト）… `04`
5. 割り勘（参加者）… `06`
6. 空の画面 … `08`

あわせて **PC幅（1280px）** で 日程（参加者）… `09` を1枚。

### 7-2. 納品物

1. **CSS** — そのまま貼り付けられる形で。すべて `:root[data-theme="chiikawa"]` から始まるセレクタで書いてください
   ```css
   :root[data-theme="chiikawa"] .card { … }
   :root[data-theme="chiikawa"] .card-title { … }
   ```
   色を変える場合は、今の色トークン（`--green` など）の値の変更として書いても構いません
2. **フォント** — 変える場合は Google Fonts の日本語対応フォントに限り、`<link>` の URL も
3. **新しい画像の一覧** — 必要な場合のみ。場所・寸法・どんな絵か
4. **画面モック** — 7-1 の7枚
