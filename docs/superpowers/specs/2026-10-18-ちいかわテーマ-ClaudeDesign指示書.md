# 調整くん「ちいかわ」テーマ — Claude Design 向け指示書

作成日: 2026-10-18
依頼者: 調整くんのオーナー
実装担当: Claude Code（この指示書の納品物を受け取り、アプリに組み込みます）

---

## 1. お願いしたいこと

飲み会の幹事アプリ「調整くん」に、**イベントごとに選べる2つ目の配色テーマ「ちいかわ」**を追加します。
そのテーマの見た目（配色・形・フォント・キャラクター画像の置き方）をデザインしてください。

いまのアプリは「Olive Lounge」というオリーブ色と生成り色の落ち着いたテーマ1つだけです。
ちいかわテーマは、**ゆるくて丸い、パステル調のかわいらしい雰囲気**にしたいと考えています。

**画面の構成・ボタンの位置・文言は変えません。** 変えるのは「色・角の丸み・影・フォント・キャラクター画像の追加」だけです。

---

## 2. 調整くんについて

飲み会・歓迎会などの幹事が使う、無料のWebアプリ（スマホ中心）です。1つのイベントURLの中に次の画面があり、上部のナビで切り替えます。

| ナビ | 内容 |
|---|---|
| 日程 | 候補日ごとに参加者が ◯（参加できる）△（たぶん）✕（参加できない）を付ける表。ホストが開催日を「確定」する |
| お店 | お店探し（外部の画面を埋め込み） |
| お知らせ | 集合時間・お店・会費などの案内 |
| 座席 | 卓と席を並べ、参加者をシャッフルして座席を決める |
| 割り勘 | 誰がいくら立て替えたかを記録し、精算方法（誰が誰にいくら払うか）を出す |
| 精算 | 会費の集金と支払い状況 |

- 使う人は「ホスト（幹事）」と「参加者」の2種類。参加者もイベントURLを開いて同じ画面を見ます
- **テーマはイベントごと**に決まり、そのイベントを開いた全員（ホスト・参加者）が同じテーマで見ます
- トップ画面・マイイベント一覧など、イベントの外の画面は Olive Lounge のままです
- 主な閲覧環境は **スマホ（幅390px前後）** です

---

## 3. テーマがアプリにどう組み込まれるか

アプリの色は CSS の変数（トークン）でまとめて管理しています。テーマを切り替えると、**変数の値だけが入れ替わります**。

```css
:root                       { --green: #3D5A3A; /* …オリーブの値… */ }
:root[data-theme="chiikawa"] { --green: ???????; /* …ちいかわの値… */ }
```

つまりデザインでは、**下の表のトークン名ごとに「ちいかわの値」を決めていただく**のが中心になります。トークン名は変えず、値だけを決めてください。

### 4-2. 形とフォント

| トークン | 用途 | オリーブの値 | ちいかわの値 |
|---|---|---|---|
| `--radius` | カードの角の丸み | `20px` | |
| `--radius-sm` | 小さな部品の角の丸み | `12px` | |
| `--font-ui` | 本文のフォント | `'Inter', 'Hiragino Sans', 'Noto Sans JP', …` | |
| `--font-display` | 見出し・数字のフォント | `'Montserrat', 'Hiragino Sans', …` | |

- フォントは **Google Fonts の無料フォントで、日本語に対応したもの**に限ります（例：Zen Maru Gothic、M PLUS Rounded 1c、Kosugi Maru）。読み込むウェイトも指定してください
- 主ボタンの形（角丸か、両端が丸いピル型か）も決めてください

### 4-3. キャラクター画像の枠

**キャラクターの絵は、オーナーが用意する画像を使います。** デザインでは絵を描かず、**位置と寸法が分かる枠（「キャラ画像」と書いた点線の枠など）**を置いてください。

| 場所 | いつ出るか | 表示サイズの目安 | 用意する画像 |
|---|---|---|---|
| ① ヘッダー | 常に（アプリ名「調整くん」の左のロゴの位置） | 40px前後 | 透過PNG・正方形・256×256px |
| ② 空の画面 | 何も無いときの案内文の上 | 96〜120px | 透過PNG・正方形・480×480px |
| ③ 確定のお祝い | 日程の「確定」を押したとき／座席のシャッフルが終わったとき（約2秒、画面中央。いまも紙吹雪の演出があります） | 200〜260px | 透過PNG・正方形・800×800px |

②が出る空の画面は次のとおりです。案内文の上に画像を添える形を、1〜2画面で見せてください。

- まだ立替がありません。「＋ 立替を追加」から記録してください。
- この次会の座席はまだ決まっていません。ホストの確定をお待ちください。
- 参加者・卓を設定して「席を決める」を押すと、ここに座席表が表示されます。
- 集合時間・お店はまだ設定されていません。
- 精算はまだ公開されていません。
- 日程調整の準備中です。しばらくお待ちください。

画像の寸法や比率を変えたほうがよい場合は、理由と一緒に提案してください。

### 4-4. 画面モック（アートボード）

スマホ幅（390px）で、次の画面をちいかわテーマで描いてください。

1. **日程（ホスト）** — 候補日の表、◯△✕、確定ボタン、「登録する」、ナビ、ヘッダー（①の枠つき）
2. **日程（参加者）** — 同じ表を参加者が見たとき
3. **座席** — 卓と席チップ、固定した席（金の枠）、空席（点線）
4. **割り勘（参加者）** — 精算結果（誰が誰にいくら）、立替カード、メンバーのまとめ行
5. **空の画面** — ②の枠を使った例
6. **確定のお祝い** — ③の枠を使った演出

比較のため、1の画面だけ **Olive Lounge（いまの配色）でも並べて**描いていただけると助かります。

## 5. 守ってほしいこと

1. **トークン名は変えない。** 値だけを決めてください。名前が違うと差し替えられません
2. **◯・△・✕ の3色は、ひと目で区別できること。** さらに ✕ と「削除」は同じ色系統です。主役の色（`--green`）は ◯ と主ボタンに使われるので、✕ と紛らわしい色にしないでください
3. **文字が読めること（WCAG AA）。** ちいかわの値で、次の組み合わせはコントラスト比 4.5 以上にしてください（実装側でも自動テストで確かめます）
   - 白い文字 × `--green`（主ボタン）
   - `--text` × `--bg` / `--surface`
   - `--text-muted` × `--bg` / `--surface`
   - `--gold-text` × `--gold-tint`
   - `--on-dark` × `--forest`

   参考までに、いまのオリーブは `--gold-text` × `--gold-tint` だけ 4.17 で、この基準をわずかに下回っています（確定した日付の金文字）。オリーブは今回変えませんが、ちいかわでは 4.5 以上にしてください。叩き台の値は、白 × 主役 `#46749F` が 4.93、本文 `#3A3438` × 背景 `#FFFAF7` が 11.73 です。
4. **明るい配色のみ。** 暗い背景（ダークモード）は今回作りません
5. **座席の色タグ5色は変えない。** 参加者をグループ分けする色で、保存データとして使っています。ちいかわテーマの上に置いても見分けられるかだけ確認してください
   - オリーブ `#3D5A3A`／ブラス `#B0883A`／テラコッタ `#B65F45`／ブルーグレー `#5C6F80`／プラム `#7A5260`
6. **画面の構成・文言・ボタンの位置は変えない。** 変えてよいのは色・角の丸み・影・フォント・画像の追加です
7. **キャラクターの絵は描かない。** 枠と寸法だけを置いてください（4-3）

## 6. 叩き台（現時点の提案）

実装側で考えた方向です。よりよい案があれば変えてください。

- **主役の色はピンクではなく水色。** ◯ は主役の色、✕ はローズ系です。主役をピンクにすると ✕ と見分けにくくなるため、◯＝水色、△＝黄色、✕＝ローズと3色を分け、ピンクは背景のほんのりした色と差し色に回しています
- 叩き台の値: 主役 `#46749F`（水色）、△ `#D4A12C`（黄色）、✕ `#D0566C`（ローズ）、差し色 `#F2A7B8`（ピンク）、背景 `#FFFAF7`、ピンクの淡い面 `#FFF1F4`、ピンクの枠 `#F6D2DB`、本文 `#3A3438`
- 角を大きめに丸め、主ボタンと ◯△✕ はピル型
- フォントは丸ゴシック（Zen Maru Gothic など）

## 7. 納品の形

次の3点をお願いします。

1. **CSS** — そのまま貼り付けられる形で
   ```css
   :root[data-theme="chiikawa"] {
     --green: #……;
     /* 4-1・4-2 の全トークン */
   }
   ```
   あわせて、フォントを読み込む Google Fonts の `<link>` の URL
2. **画像の寸法表** — 4-3 を確定したもの（変更があれば理由も）
3. **画面モック** — 4-4 の6画面（＋オリーブとの比較1画面）

モックに出てくる色が、すべて上のトークンのどれかに当てはまるようにしてください。表に無い色が必要になった場合は、**新しいトークン名・用途・値**を追加で書き出してください（実装側でトークンを足します）。
